# GridPulse — Edge AI Load Forecasting

GridPulse is an Edge AI prototype designed for intelligent electrical grid monitoring and load forecasting at distribution substations. It demonstrates how lightweight AI models can run directly on edge devices to provide fast predictions and detect abnormal load conditions without relying on a cloud round trip.

## Overview

The prototype simulates multiple distribution substations, each running an on-device load forecasting model. Real-time load data is generated, analyzed locally, and displayed through an interactive monitoring dashboard.

The system demonstrates the advantages of edge-based intelligence, including low inference latency, local anomaly detection, and reduced dependency on cloud processing.

## AI Model

GridPulse uses **Holt's Linear Trend Exponential Smoothing** as a lightweight forecasting approach.

The model maintains:

* Level
* Trend
* Previous observations
* Next-step forecast

This approach is suitable for demonstrating edge-based forecasting because it requires relatively small computational and memory resources compared with larger machine-learning models.

## Prototype Architecture

The prototype contains five simulated substations:

* Substation A — Riverside
* Substation B — Foundry District
* Substation C — Harbor Point
* Substation D — Uplands
* Substation E — Central Yard

Each substation has its own simulated load pattern and forecasting state. The dashboard allows users to select a substation and inspect its current load, forecast, forecast error, and decision history.

## Edge AI Advantage

Traditional cloud-based processing requires data to travel from the grid device to a remote server and back. GridPulse demonstrates a different approach where the forecasting model operates directly at the edge.

```text
Cloud Approach:
Sensor → Network → Cloud → AI Model → Network → Decision

Edge Approach:
Sensor → Edge AI → Decision
```

The prototype also provides a visual comparison between simulated edge inference latency and an equivalent cloud round trip.

## Anomaly Detection

The system continuously compares actual load with the forecast generated by the edge model.

When the deviation exceeds the defined threshold, the substation is locally flagged as anomalous and an entry is added to the edge decision log.

The prototype also provides an **Inject Anomaly** feature to simulate a sudden load spike and observe the response of the edge model.
